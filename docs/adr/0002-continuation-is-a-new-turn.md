# A Continuation is a new Turn with a Resume message

The installed host has no public promptless continue. A Continuation is a new Turn started by one plugin-sourced Resume message. It is not a replay of the previous Turn, Step, or tool batch, and it is not a resend of the original prompt. The Resume message is not a Human message and is not a grant of permission. Editing the Agent Loop to resume with no new input would match a promptless continue more closely, and was rejected because it forks the host.
